## 🌟 專案簡介 (Introduction)

**Lattice Color Hunt** 是為了「行動載具應用程式設計入門」課程所開發的人生第一個 App。

我們將材料科學中抽象而浪漫的微觀世界搬到了行動裝置上。在這個 App 中，完美的幾何排列不再枯燥，玩家將化身為一位**小小科學家**，展開一場尋找晶體缺陷與探索色彩的微觀冒險！

---

## 🎮 遊戲故事與核心機制 (Game Concept & UI Flow)

* **Loading View（載入視圖）**：
  進入遊戲時，系統會隨機挑選一種**晶體系統（Crystal System）**，建構出 Game View 中特定的幾何外形，引領玩家準備進入微觀世界。
* **Game View（遊戲主畫面）**：
  玩家扮演一位拿著放大鏡的小小科學家，進入微觀的晶體世界。在整齊排列、看似一模一樣的晶格網格中，隱藏著各種代表著獨特色彩的缺陷。
* **缺陷與色彩的交織**：
  每一個與母體不同的顏色點，都代表著一種獨一無二的晶體缺陷（就像紅寶石因為鉻離子取代了鋁的缺陷而呈現迷人的紅色一樣）。玩家必須運用敏銳的觀察力，將這些美麗的缺陷通通找出來！

---

## ✨ 主要功能特色 (Key Features)

- 🔬 **跨領域美學結合**：將結晶學概念融入遊戲化互動，兼具科普教育與娛樂性。
- 🎲 **動態隨機生成**：每次進入遊戲隨機載入不同晶體結構與色彩缺陷分佈。
- 📱 **直覺觸控互動**：專為行動載具設計的流暢點擊與色彩回饋體驗。
- 🤖 **AI 協同開發**：從架構發想、邏輯除錯到 UI 優化，全程透過 AI 輔助完成。
