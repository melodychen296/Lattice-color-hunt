# Lattice Color Hunt

> **「在材料科學中，完美的晶格往往是單調乏味的，而正是那些大大小小的晶體缺陷，賦予了材料獨特的物理性質與璀璨的色彩。」**

---

## 專案簡介

**Lattice Color Hunt** 是「行動載具應用程式設計入門」課程中我的第一個人機協作專案。我將材料科學中抽象的微觀晶格與晶體缺陷概念，轉化為一場結合科普教育與視覺尋寶的趣味小遊戲。

---

## 遊戲玩法與流程 (App Flow)

1. **Home View（首頁）**
   - 簡約美觀的入口介面，可以選擇難度點擊按鈕即可化身「小小科學家」展開探索。
2. **Loading View（科普過場）**
   - 隨機載入一項晶體系統與實用的材料科學小知識（例如寶石顏色與缺陷的關係）。
3. **Countdown（倒數準備）**
   - 3、2、1 倒數計時，集中注意力準備進入微觀世界。
4. **Game View（遊戲主畫面）**
   - 在整齊排列的晶格網格中，尋找那些因為「晶體缺陷」而綻放出不同色彩的目標點。
5. **Result View（結算畫面）**
   - 統計找出的缺陷數量與花費時間，解鎖科學家專屬評語與成就！

## AI 協同開發亮點

因應開發環境的額度限制，本專案採取了**「網格化 Prompt 策略」**：
- 先在外部 AI 介面中，將抽象的遊戲邏輯（首頁、科普過場、倒數、遊戲主軸、結算）逐步梳理成結構化指令。
- 再帶回 Xcode 中進行實作與除錯，實現流暢的人機協作開發流程。
